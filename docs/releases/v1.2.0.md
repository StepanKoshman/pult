В Пульт добавлен измеритель USB **ALIENTEK C2** (Lite, Std, Pro). Выпуск объединяет его с поддержкой tinySA из 1.1.0.

## Что нового

- **C2:** напряжение и ток VBUS, мощность, напряжения D+ и D−. Рабочий стол «C2» с большим показанием, таблицей и трендом.
- **Подключение C2:** по USB (WebUSB, драйвер WinUSB Windows ставит сама), по Bluetooth LE (Std и Pro) и через COM-порт или Bluetooth SPP.
- **C2 только читается:** команды записи и вход в обновление прошивки в драйвер намеренно не включены.
- **LT1:** набор частот берётся из версии прошивки. С fix5 2.3 верхняя частота 50 кГц, раньше 100 кГц; ось АЧХ следует за данными.
- **Демо** запускает четыре симулятора: LT1, DM40, tinySA и C2.

## Как запустить

Скачайте `pult.html` и откройте его в Chrome или Edge. Установка не нужна. Для Firefox и Safari нужен мост `bridge.py` (см. README).

## Проверка

Проверено в браузере на встроенных симуляторах: все четыре прибора подключаются и дают данные. С настоящим C2 выпуск не проверялся, масштаб величин в драйвере предварительный. Частоты LT1 для fix5 2.3 с прибором тоже не сверялись.
